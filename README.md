# Agriculture Extension SF Rahu (AESFR) — زرعی رہنما

**AESFR (Agriculture Extension Shaheed Fazil Rahu)** is a comprehensive mobile-first digital advisory application built specifically for farmers and Agriculture Extension officers in Sindh, Pakistan (Taluka Golarchi / SF Rahu, District Badin).

> **Credit:** This app made by Sagar Saleem Chang

---

## 🌟 اہم خصوصیات (Core Features)

1. **کسان گائیڈ AI (AI Farmer Assistant):**
   - اردو، سندھی اور انگریزی میں کسانوں کے سوالات کے بروقت اور مقامی جوابات۔
   - سرور سائیڈ Gemini AI انٹیگریشن۔
   - سندھ کے مخصوص موسمی حالات (بدین کا ساحلی موسم، کوٹری بیراج سے نہری پانی، ٹیل کے مسائل، سیم و تھور) کے مطابق گائیڈنس۔
   - غیر مصدقہ زہروں یا ادویات کے بغیر محفوظ ثقافتی تدابیر۔

2. **فصل کی بیماری شناخت کریں (Crop Disease Detection):**
   - موبائل کیمرے یا گیلری سے پتے، تنے یا پھل کی تصویر کا سرور سائیڈ ملٹی ماڈل تجزیہ۔
   - علامات، ممکنہ اسباب، یقین کا درجہ (Confidence Level)، اور فوری محفوظ غیر کیمیائی اقدامات۔
   - غیر واضح تصویر پر واضح وارننگ اور متعلقہ زرعی آفیسر سے معائنے کی ہدایت۔

3. **براہِ راست موسم (Live Weather via Open-Meteo):**
   - گولارچی (SF Rahu) اور سندھ کے دیگر مراکز کا لائیو درجہ حرارت، نمی، ہوا کی رفتار اور 7 روزہ زرعی پیش گوئی۔
   - آف لائن کیشنگ اور واضح ڈیٹا ریٹریول ٹائم کا لیبل۔

4. **سرکاری اسکیمیں اور سبسڈی (Government Schemes):**
   - سندھ ہاری کارڈ (بے نظیر ہاری کارڈ)، گندم امدادی قیمت، سولر ٹیوب ویل اور لیزر لینڈ لیولنگ کے مصدقہ سرکاری ریکارڈز۔
   - تصدیق شدہ حکومتی ذرائع، اہلیت کا معیار، درکار دستاویزات اور سرکاری پورٹل لنکس۔

5. **محکمے کے نوٹس و الرٹس (Department Notices):**
   - گلابی سنڈی، سفید مکھی اور نہری وارہ بندی کے سرکاری انتباہات۔

6. **فصلوں کی جامع معلومات (Crop Knowledge Base):**
   - کپاس، دھان، گندم، کماد، سرخ مرچ اور سورج مکھی کی مرحلہ وار آف لائن گائیڈز (بوائی، آبپاشی، کھاد، کیڑے اور برداشت)۔

7. **شہید فاضل راہو کے 5 فیلڈ سرکلز (SF Rahu Circles):**

   - **راہوکی سرکل:** AO Javed Akhiyar Khaskheli

   - **کڑیو سرکل:** AO Javed Akhiyar Khaskheli
   - **گولارچی مرکز:** AO Nehal Ahmed

8. **رابطہ برائے محکمہ زراعت (Contact Office):**
   - **صرف واٹس ایپ:** `03430505419` (کوئی فون کال بٹن نہیں ہے)۔

   - گوگل میپس ڈائریکشنز لنک۔

9. **محفوظ ایڈمن پورٹل (Admin Portal):**
   - فیلڈ آفیسرز کے لیے محفوظ پاس کوڈ تصدیق تاکہ نئے سرکاری نوٹس اور اسکیمیں باآسانی شائع کی جا سکیں۔

10. **آف لائن اور کم انٹرنیٹ موڈ (Offline & PWA):**
    - 2G اور کمزور سگنل والے دیہات کے لیے "کم انٹرنیٹ موڈ"۔
    - PWA انسٹال سپورٹ (Add to Home Screen)۔

## 🚀 چلانے اور ٹیسٹ کرنے کا آسان طریقہ (How to Run and Test)

### 1. عام لوکل رن (Local Development)
```bash
# پیکجز انسٹال کریں
npm install

# سرور اور فرنٹ اینڈ شروع کریں (پورٹ 3000 پر چلے گا)
npm run dev
```

ایپ براؤزر میں `http://localhost:3000` پر خود بخود فعال ہو جائے گی۔

### 2. بیک اینڈ ٹیسٹ چلانا (Run Automated API Tests)
```bash
npm test
```
یہ اسکرپٹ سرور کی ہیلتھ، اوپن میٹیو لائیو ویدر، اسکیمز، نوٹسز، سرکل آفیسرز اور جیمنی ان پٹ ویلیڈیشن کو خودکار طریقے سے ٹیسٹ کرتا ہے۔

## 🔑 ماحول کے متغیرات (Environment Variables)

`.env` فائل میں درج ذیل متغیرات کی ضرورت ہوتی ہے:

```env
# Gemini API Key: سرور سائیڈ AI چیٹ اور بیماری کی تصویری تشخیص کے لیے درکار ہے۔
# Google AI Studio میں یہ خودکار طور پر شامل ہو جاتی ہے۔
GEMINI_API_KEY="your-gemini-api-key-here"

# App URL: ہوسٹڈ ایپ کا ایڈریس
APP_URL="https://your-app-domain.run.app"

# Admin Passcode: محکمہ کے فیلڈ افسران کے لیے ایڈمن پورٹل کا پاس کوڈ
ADMIN_ACCESS_CODE="AESFR_ADMIN_2026"
```

## 📱 اینڈرائیڈ اے پی کے (Android APK) تیار کرنے کا طریقہ

اس ایپ کو کیپیسیٹر (Capacitor) کے ذریعے باآسانی ایک مکمل اینڈرائیڈ APK میں تبدیل کیا جا سکتا ہے:

1. **کیپیسیٹر ٹولز انسٹال کریں:**
   ```bash
   npm install @capacitor/core @capacitor/android
   npm install -D @capacitor/cli
   ```

2. **کیپیسیٹر کنفیگر کریں:**
   ```bash
   npx cap init "Agriculture Extension SF Rahu" "com.aesfr.sindh.agro" --web-dir "dist"
   ```

3. **ویب بلڈ بنائیں اور اینڈرائیڈ پراجیکٹ سنک کریں:**
   ```bash
   npm run build
   npx cap add android
   npx cap sync
   ```

4. **اینڈرائیڈ اسٹوڈیو میں کھول کر APK بنائیں:**
   ```bash
   npx cap open android
   ```
   - اینڈرائیڈ اسٹوڈیو میں **Build > Build Bundle(s) / APK(s) > Build APK(s)** پر کلک کریں۔
   - بننے والی APK فائل کسانوں کے فونز پر براہ راست انسٹال کی جا سکتی ہے۔

## 🔔 پش نوٹیفیکیشنز (FCM) کنفیگریشن کی وضاحت

- **موجودہ صورتحال:** ایپ میں معیاری Web Notifications API پہلے سے مکمل طور پر کوڈڈ ہے، جو براؤزر اور PWA میں فوری چلتا ہے۔
- **اینڈرائیڈ پسِ منظر نوٹیفیکیشنز:** جب ایپ بند ہو، تو ریموٹ پش نوٹیفیکیشنز بھیجنے کے لیے گوگل فائر بیس پراجیکٹ بنا کر `google-services.json` فائل اینڈرائیڈ فولڈر میں رکھی جاتی ہے اور سرور سائیڈ پر `firebase-admin` کنفیگر کیا جاتا ہے۔
